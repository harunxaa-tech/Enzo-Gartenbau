Hinweise:

- Telefon, E-Mail, Routenlink und das Kontaktformular funktionieren ohne Backend. Das Formular öffnet das E-Mail-Programm des Besuchers mit einer vorbereiteten Nachricht.
- Es werden in dieser Version keine Analyse- oder Marketing-Cookies eingebaut.
- Die Galeriebilder stammen aus dem aktuellen Webauftritt von enzogiardino.de und werden von dort geladen. Für einen vollständig unabhängigen Umzug sollten die Originalbilder später lokal in das Projekt übernommen werden.
- Impressum und Kontaktdaten wurden anhand des aktuellen Webauftritts übernommen. Datenschutz/Rechtstext wurde technisch auf diese statische Version angepasst und sollte vor einer endgültigen geschäftlichen Veröffentlichung rechtlich geprüft werden.
